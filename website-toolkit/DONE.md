# Definition of done
A site is not done because it compiles. Every item needs evidence in the final report.

- [ ] Typecheck, lint, tests and production build pass (paste output summary).
- [ ] Screenshots captured and viewed at 375, 768 and 1440 px for every key page.
- [ ] No horizontal scroll and no obvious layout shift in those screenshots.
- [ ] Key interactions exercised in a real browser (nav, forms, menus, media).
- [ ] axe: zero serious or critical violations.
- [ ] Lighthouse CI budgets pass (set LCP/CLS/JS thresholds per project).
- [ ] Keyboard-only navigation works with visible focus.
- [ ] prefers-reduced-motion verified.
- [ ] Design lint run (npx impeccable detect) and findings fixed or justified.
- [ ] Metadata, OG image, sitemap, robots, 404 page present.
- [ ] Known issues and unverified items listed honestly.
- [ ] Human art-direction review requested.
